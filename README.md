# Machine Learning

A comprehensive collection of Machine Learning algorithms, projects, and implementations using Python and Scikit-learn.

This repository is created as a learning and portfolio project to understand Machine Learning algorithms through practical, real-world datasets.

---

## 📚 Machine Learning Projects

### 01. Linear Regression

Linear Regression is a supervised learning algorithm used to predict continuous numerical values.

#### Projects

##### 01. Salary Prediction

Predict employee salary based on years of experience using Simple Linear Regression.

**Features:**
- Years of Experience

**Target:**
- Salary

**Techniques Covered:**
- Data Loading
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Correlation Analysis
- Train-Test Split
- Simple Linear Regression
- Model Prediction
- MAE
- MSE
- RMSE
- R² Score
- Model Fit Analysis
- Model Saving using Joblib
